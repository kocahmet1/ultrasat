      Micro-lesson · written for you
      
Singular vs. plural possessives — the 60-second version

      
Why now: twice tonight (and twice on Jun 30) you placed the apostrophe before the -s on a plural noun. One small rule, and it keeps costing you Boundaries points.

      
The rule: build the noun first, then attach the possessive. If the plural already ends in -s, the apostrophe goes after it.

      

        
the student's bookone student → student + 's

        
the students' booksmany students → students + '

      

      
Your sentence, fixed: you chose "the three visitor's badges." Three visitors → plural first (visitors), then the apostrophe: "the three visitors' badges."

      

        Quick check
        
        
        
Exactly — several senators, plural first, apostrophe after the -s. That's the whole rule.

        
Not quite — there are several senators, so the plural comes first: senators + ' .

The render pipeline

    

      
Engine (as-is)
observer · debrief · chat · micro-lesson
Tier-2 + notebook grounding

      →
      
Note with blocks
blocks:[verdict, plan, focus, stat…]
validated server-side like actions are today

      →
      
Block renderer
one React component: <CoachBlocks/>
maps block type → kit component

      →
      
Surfaces
Home hero · HQ · results takeover · dock peek — each picks the blocks it wants

    

    

    
Fallback chain (why it never breaks): fresh note with blocks → cached note → mechanical brief rendered
    straight from Tier-2 with zero LLM (the "quiet day" scenario on tab 1). A message-only note from the current prompt renders as a verdict
    card — so shipping the UI does not require shipping the new prompt.

    Why this beats a better chat
    

      A chat box makes the model responsible for presentation — and models present generically. Blocks make the model responsible only for
      judgment (what matters now, what to do next), which is the part it's actually good at. The UI stays deterministic, on-brand, testable,
      and cheap to render; the "personality" comes from real specificity — your dates, your misses, your pattern — not from prose style.
      And every block is one the student can tap: the coach stops narrating the app and starts driving it.
