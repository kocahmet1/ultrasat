# Practice Test 9 — Reading & Writing — AUTHORING BLUEPRINT

## Non-negotiable form laws (measured 264/264 items, zero exceptions)

1. **Domain order within a module is fixed and never interleaves:**
   `Craft and Structure` → `Information and Ideas` → `Standard English Conventions` → `Expression of Ideas`
2. **Skill order inside each domain is fixed:**
   - C&S: words-in-context → text-structure-purpose → cross-text-connections
   - I&I: central-ideas-details → command-of-evidence → inferences
   - EOI: transitions → rhetorical-synthesis
   - **SEC is the exception:** boundaries and form-structure-sense are deliberately *interleaved*,
     not grouped. The block opens with a form-structure-sense item (8/8 official modules) and
     closes with a boundaries item (7/8).
3. **Difficulty is monotone non-decreasing inside every skill block** (82 concordant / 0 discordant
   pairs). Every block opens easy-end and closes hard-end.
   **For the SEC block the ladder runs across the whole domain, irrespective of which of the two
   skills the item belongs to.**
4. Longest same-letter answer run observed is 4; a run of 5 never occurs. Target ≤2 in a row.

Distractors must come from **three different relationship categories, none matching the key's**
(92%/97% of official items). Bait with `for example`, `similarly`, `in other words` — the three
most over-used distractors in the official bank. **Never test a conditional relationship.**

### Literary passages (the `The following text is …` preamble)

Exactly **four** per form, and only in these slots: M1 Q5 (words-in-context, hard),
M1 Q7 (text-structure-purpose, hard), M2 Q1 (words-in-context, easy),
M2 Q8 (central-ideas-details, easy). One of the four must be a poem.
**No literary passage in any Conventions, Transitions, or Rhetorical Synthesis item.**

## Hard prohibitions

- **No text, name, topic, finding, artwork, or study from any official item.** `/tmp/avoid_names.txt`
  holds 1,806 proper nouns harvested from the official bank and from repo Tests 3 and 4 — grep every
  name you invent against it.
- No real living researchers. Invented researchers must be plausible and non-Anglo-skewed, matching
  the field and region of the topic.
- No factual claim that a knowledgeable reader would recognize as false about the real world.
  Invented specifics must be *fictional but not counterfactual* — describe a plausible unnamed
  study, not a wrong fact about a known one.
