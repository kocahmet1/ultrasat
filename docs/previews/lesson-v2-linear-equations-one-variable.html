Linear Equations in One Variable

A linear equation in one variable is an equation whose variable appears only to the first power—no exponents, no square roots, no variable in a denominator. Every one of them can be rearranged into the form $ax + b = c$, where $a$, $b$, and $c$ are numbers.

  • $3x + 5 = 11$
    The variable is raised only to the first power — linear.
  • $\frac{x}{4} - 2 = 7$
    Dividing the variable by a number is still linear.
  • $x^2 + 1 = 5$
    The variable is squared — that's a quadratic, not linear.
  • $\frac{3}{x} = 6$
    The variable sits in a denominator — not linear.

Solving an equation means finding the value of the variable that makes both sides equal. On the SAT you'll solve equations directly, build them from word problems, and reason about how many solutions an equation has—this lesson covers all three.

Strategies

  • Keep the equation balanced. Whatever you do to one side, do to the other—always.
  • Undo operations with their inverses to peel everything away from the variable.
  • Variables on both sides? Collect the $x$-terms on one side and the numbers on the other.
  • Asked for an expression (like $6x - 10$)? Look for a shortcut before solving for $x$.
  • Check your answer by plugging it back in—or, on multiple choice, plug in the choices.

Inverse Operations

Every solving move is an undo. An equation was built by doing operations to $x$; you solve it by undoing them with each operation's inverse, working in reverse order of operations.

Addition⇄Subtraction
Multiplication⇄Division
Think of solving as unwrapping: the last operation done to $x$ is the first one you undo.
AlgebraLinear Equations in One Variable: Solve for a Value

Solve for a Value

To solve for the variable, isolate it: move everything else to the other side, one inverse operation at a time. Undo addition and subtraction first, then multiplication and division.

Example

What value of $x$ satisfies the equation below?

$$5x + 7 = 42$$
Given equation
$$5x = 35$$
Subtract $7$ from both sides
$$x = 7$$
Divide both sides by $5$

Check: $5(7) + 7 = 35 + 7 = 42$ ✓ — the solution works.

Variables on Both Sides

When the variable appears on both sides, collect the $x$-terms on one side and the numbers on the other—then finish as usual.

Example

What value of $x$ satisfies $2x + 9 = 4x - 1$?

$$2x + 9 = 4x - 1$$
Given equation
$$9 = 2x - 1$$
Subtract $2x$ from both sides
$$10 = 2x$$
Add $1$ to both sides
$$5 = x$$
Divide both sides by $2$
Collect the $x$-terms on the side with the larger coefficient—here, the right side—so the coefficient stays positive and sign errors stay away.

Distribute First

If the equation has parentheses, distribute before anything else—then it becomes a familiar two-side equation.

Example
$$3(x - 4) = 2x + 1$$
Given equation
$$3x - 12 = 2x + 1$$
Distribute the $3$
$$x - 12 = 1$$
Subtract $2x$ from both sides
$$x = 13$$
Add $12$ to both sides

Clear Fractions

A fraction is just a division—undo it by multiplying both sides by the denominator, ideally as your first move.

Example
$$\frac{2x + 1}{5} = 3$$
Given equation
$$2x + 1 = 15$$
Multiply both sides by $5$
$$2x = 14$$
Subtract $1$ from both sides
$$x = 7$$
Divide both sides by $2$
On multiple-choice questions you can also work backward: plug each answer choice into the equation and keep the one that makes both sides equal.
AlgebraLinear Equations in One Variable: Solve for an Expression

Solve for an Expression

Some questions never ask for $x$. They give you an equation and ask for the value of an expression—and the fastest route is usually not to solve for $x$. Compare the target expression with the given equation first: it's often a multiple of it.

Example

If $4x + 3 = 19$, what is the value of $12x + 9$?

Shortcut: scale the equation
$$4x + 3 = 19$$
Given equation
$$3(4x + 3) = 3(19)$$
$12x + 9$ is $3$ times the left side
$$12x + 9 = 57$$
Simplify
Or: solve for x first
$$4x = 16$$
Subtract $3$ from both sides
$$x = 4$$
Divide both sides by $4$
$$12(4) + 9 = 57$$
Plug $x = 4$ into $12x + 9$

Both routes work—but the shortcut is fewer steps, and fewer steps means fewer chances for an arithmetic slip.

Rule: Before solving for $x$, compare the target expression with the given equation. If the target is a multiple of it, transform the whole equation instead of solving.

Example

If $3x - 5 = 16$, what is the value of $6x - 10$?

  1. A)$7$
  2. B)$21$
  3. C)$32$
  4. D)$42$
Process of Elimination:
  • Choice A: $7$ is the value of $x$ itself—the classic trap. The question asks for $6x - 10$, not $x$.
  • Choice B: $21$ is the value of $3x$—stopping one step short of anything the question asked.
  • Choice C: $6x - 10 = 2(3x - 5)$, so its value is $2(16) = 32$. (Solving instead also works: $x = 7$, and $6(7) - 10 = 32$.)
  • Choice D: $42$ is the value of $6x$ alone—the $- 10$ still has to be applied.
When a question asks for an expression, the value of $x$ is almost always sitting among the wrong choices. Answer the question that was actually asked.
AlgebraLinear Equations in One Variable: How Many Solutions?

How Many Solutions?

A linear equation in one variable doesn't always have exactly one solution. To find out how many it has, simplify both sides completely and look at what's left:

What simplifying leavesExampleNumber of solutions
$x =$ a number$x = 5$Exactly one
A false statement$5 = 3$None — “no solution”
A true statement$12 = 12$Infinitely many
Example

How many solutions does the equation $4(2x + 3) = 8x + 12$ have?

$$4(2x + 3) = 8x + 12$$
Given equation
$$8x + 12 = 8x + 12$$
Distribute the $4$
$$12 = 12$$
Subtract $8x$ from both sides

The $x$-terms vanished and left a true statement—the equation holds no matter what $x$ is. It has infinitely many solutions.

A Picture of the Three Cases

Treat each side of the equation as its own line: $y = \text{left side}$ and $y = \text{right side}$. A solution is an $x$-value where the two lines meet.

Exactly one
None
Infinitely many
Example

In the equation $6x + k = 3(2x + 5)$, $k$ is a constant. If the equation has infinitely many solutions, what is the value of $k$?

  1. A)$3$
  2. B)$5$
  3. C)$15$
  4. D)$30$
$$6x + k = 3(2x + 5)$$
Given equation
$$6x + k = 6x + 15$$
Distribute the $3$
$$k = 15$$
Identical $x$-terms — the constants must match too
Process of Elimination:
  • Choice A: $3$ is just the multiplier outside the parentheses, not the matched constant.
  • Choice B: $5$ is the constant inside the parentheses—before the $3$ has been distributed.
  • Choice C: After distributing, the right side is $6x + 15$. The $x$-terms already agree, so the equation is true for every $x$ exactly when $k = 15$.
  • Choice D: With $k = 30$, subtracting $6x$ leaves $30 = 15$—a false statement, which means no solution rather than infinitely many.
AlgebraLinear Equations in One Variable: Equations from Context

Equations from Context

Many SAT linear equations arrive as word problems. Nearly all of them are built from the same skeleton:

Total=Starting amount+Rate×Quantity
Words in the problemMath
“each,” “per,” “every”a rate — it multiplies the quantity
“one-time fee,” “initial,” “starts with”a constant added once
“total,” “altogether,” “in all”the result of the sum
“is,” “was,” “will be”the equals sign
Example

A moving company charges a one-time fee of $\$55$, plus $\$65$ for each hour of work. If a move costs $\$380$ in total, how many hours did it take?

Map the words onto the skeleton: the total is $380$, the starting amount is the $55$ fee, and the rate of $65$ per hour multiplies the number of hours $h$:

$$\textcolor{#157f4b}{380} = \textcolor{#0f6cbd}{55} + \textcolor{#0e8a7e}{65}\textcolor{#6d3fc4}{h}$$
$$325 = 65h$$
Subtract $55$ from both sides
$$h = 5$$
Divide both sides by $65$

The move took 5 hours. Check: $55 + 65(5) = 55 + 325 = 380$ ✓

Example

Amara puts $\$220$ on a transit card and spends $\$14$ from it each week. If $\$52$ remains on the card after $w$ weeks, which equation represents this situation?

  1. A)$220 - 14w = 52$
  2. B)$220 + 14w = 52$
  3. C)$14w - 220 = 52$
  4. D)$52 - 14w = 220$
Process of Elimination:
  • Choice A: Spending removes money: start at $220$, subtract $14$ per week, land on $52$. (Solving it gives $w = 12$ weeks—a reasonable number.)
  • Choice B: Adds the spending, so the balance would grow each week—the opposite of the story.
  • Choice C: Reverses the roles: it subtracts the starting balance from the spending, which has no meaning here.
  • Choice D: Treats the leftover $52$ as the starting amount and the $220$ as the result—the story run backward.
Before solving, sanity-check the equation's story: should the total grow or shrink? Should the answer be large or small? A ten-second reality check catches most setup mistakes.
AlgebraLinear Equations in One Variable: Practice

Practice

Solve each one fully before opening the answer. If you get stuck, name the move you need: distribute, clear a fraction, collect the $x$-terms, or scale the whole equation.

Practice
  1. 1.

    What value of $x$ satisfies the equation $4x - 7 = 2x + 9$?

    1. A)$1$
    2. B)$4$
    3. C)$8$
    4. D)$16$

    The correct answer is C. Collect the $x$-terms on the left and the numbers on the right:

    $$4x - 7 = 2x + 9$$
    Given equation
    $$2x - 7 = 9$$
    Subtract $2x$ from both sides
    $$2x = 16$$
    Add $7$ to both sides
    $$x = 8$$
    Divide both sides by $2$
    Process of Elimination:
    • Choice A: $1$ comes from subtracting $7$ from $9$ and halving—skipping the collection of $x$-terms entirely.
    • Choice B: $4$ treats the equation as $4x = 9 + 7$, ignoring the $2x$ on the right side.
    • Choice C: $2x = 16$, so $x = 8$. Check: $4(8) - 7 = 25$ and $2(8) + 9 = 25$. ✓
    • Choice D: $16$ stops at $2x = 16$—the final division by $2$ is still needed.
  2. 2.

    If $\frac{x}{5} + 3 = 10$, what is the value of $\frac{x}{5} - 2$?

    1. A)$5$
    2. B)$7$
    3. C)$33$
    4. D)$35$

    The correct answer is A. No need to find $x$: the given equation already tells you that $\frac{x}{5} = 7$, so $\frac{x}{5} - 2 = 7 - 2 = 5$.

    Process of Elimination:
    • Choice A: Subtract $3$ from both sides to get $\frac{x}{5} = 7$, then subtract $2$ more: $5$.
    • Choice B: $7$ is the value of $\frac{x}{5}$—one step short of what was asked.
    • Choice C: $33$ is $x - 2$: it subtracts the $2$ from $x = 35$ instead of from $\frac{x}{5}$.
    • Choice D: $35$ is the value of $x$ itself—the question asks for $\frac{x}{5} - 2$.
  3. 3.

    In the equation $3(2x - 4) = 6x + c$, $c$ is a constant. If the equation has infinitely many solutions, what is the value of $c$?

    1. A)$-12$
    2. B)$-4$
    3. C)$4$
    4. D)$12$

    The correct answer is A. Distribute, then compare the two sides:

    $$3(2x - 4) = 6x + c$$
    Given equation
    $$6x - 12 = 6x + c$$
    Distribute the $3$
    $$c = -12$$
    Identical $x$-terms — constants must match
    Process of Elimination:
    • Choice A: With $c = -12$, both sides are the exact same expression, so every value of $x$ works.
    • Choice B: $-4$ is the constant inside the parentheses—before it has been multiplied by $3$.
    • Choice C: $4$ flips the sign of that inner constant on top of skipping the distribution.
    • Choice D: $12$ is a sign error: $3 \times (-4) = -12$, not $12$. With $c = 12$ the equation has no solution.
  4. 4.

    A climbing gym charges a one-time enrollment fee of $\$40$ plus $\$20$ per month of membership. Malik has paid the gym $\$240$ in total. For how many months has he been a member?

    1. A)$6$
    2. B)$10$
    3. C)$12$
    4. D)$14$

    The correct answer is B. Total $=$ fee $+$ rate $\times$ months:

    $$240 = 40 + 20m$$
    Build the equation from the story
    $$200 = 20m$$
    Subtract $40$ from both sides
    $$m = 10$$
    Divide both sides by $20$
    Process of Elimination:
    • Choice A: $6$ divides by the $\$40$ fee instead of the $\$20$ monthly rate.
    • Choice B: $240 - 40 = 200$ spent on monthly dues, and $200 \div 20 = 10$ months.
    • Choice C: $12$ is $240 \div 20$—it forgets the one-time enrollment fee.
    • Choice D: $14$ adds the fee instead of subtracting it: $(240 + 40) \div 20$.

Things to Remember

  • Linear means the variable appears only to the first power. Solve by undoing operations—inverse operations, reverse order, and always the same move on both sides.
  • Distribute and clear fractions first; then collect the $x$-terms on one side and the numbers on the other.
  • Asked for an expression? Check whether it's a multiple of the given equation before solving for $x$—and expect the value of $x$ among the trap choices.
  • After simplifying: $x =$ a number → one solution; a false statement → none; a true statement → infinitely many.
  • Word problems: total $=$ starting amount $+$ rate $\times$ quantity. Sanity-check the story before you solve.
  • Check your answer by plugging it back in—or plug in the answer choices.
