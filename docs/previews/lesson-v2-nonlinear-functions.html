Nonlinear Functions

A linear function changes at a constant rate—its graph is a straight line. A nonlinear function's rate of change itself changes, which bends the graph. Two families dominate the SAT: quadratic functions (parabolas) and exponential functions (growth and decay curves).

Linear
Quadratic
Exponential

Strategies

  • Evaluate like always—substitute carefully. Exponents and negative inputs are where points are lost; put substituted negatives in parentheses.
  • Know the three quadratic forms and what each displays at a glance: y-intercept, x-intercepts, or vertex.
  • Read a parabola from its equation: sign of $a$ → opens up or down; vertex → minimum or maximum; the graph is symmetric about the vertex.
  • Read an exponential as initial value $\times$ factor$^{\,x}$: factor $> 1$ grows, between $0$ and $1$ decays; percent change hides inside the factor.
  • In tables: equal $x$-steps with constant differences → linear; constant ratios → exponential.
Most nonlinear questions are recognition, not computation: which form shows the vertex, which function matches the table, what does the $0.85$ mean. Learn the fingerprints and the algebra stays light.
Advanced MathNonlinear Functions: The Parabola: Reading a Quadratic

The Parabola: Reading a Quadratic

A quadratic function $f(x) = ax^2 + bx + c$ graphs as a parabola. Every feature the SAT asks about is visible on one picture:

FeatureWhere to find itFor $f(x) = x^2 - 4x + 3$
Opens up / downsign of $a$: up if $a > 0$, down if $a < 0$$a = 1 > 0$: up
y-interceptthe constant $c$ (set $x = 0$)$(0, 3)$
Zeros / x-interceptssolve $f(x) = 0$$x = 1$ and $x = 3$
Vertex$x = -\frac{b}{2a}$ — or halfway between the zeros$(2, -1)$
Min / max valuethe vertex's $y$: minimum if opens up, maximum if downminimum $-1$

The parabola is symmetric about the dashed line through its vertex: inputs equally far from $x = 2$ give equal outputs. Since $f(0) = 3$, symmetry says $f(4) = 3$—no computation needed.

Example

For $f(x) = x^2 - 4x + 3$, what is the value of $f(5)$?

$$f(5) = (5)^2 - 4(5) + 3$$
Substitute $5$ for every $x$
$$f(5) = 25 - 20 + 3$$
Exponent first, then multiply
$$f(5) = 8$$
Add
Substituting negatives: write parentheses. For $f(x) = x^2$, $f(-3) = (-3)^2 = 9$. Typing $-3^2$ into your calculator gives $-9$—the exponent grabs the $3$ before the minus sign does.
Advanced MathNonlinear Functions: Three Forms of a Quadratic

Three Forms of a Quadratic

The same quadratic can be written three ways, and each form displays a different feature as constants you can read directly. The SAT tests this constantly with the phrase “…displays … as a constant or coefficient.”

FormTemplateShows at a glance
Standard$ax^2 + bx + c$y-intercept: $(0, c)$
Factored$a(x - r)(x - s)$x-intercepts: $r$ and $s$
Vertex$a(x - h)^2 + k$vertex: $(h, k)$

Here is the parabola from the previous page in all three costumes—same function, different features on display:

Standard
$$x^2 - 4x + \textcolor{#157f4b}{3}$$

y-intercept $(0, 3)$

Factored
$$(x - \textcolor{#c0392f}{1})(x - \textcolor{#c0392f}{3})$$

zeros at $x = 1$, $x = 3$

Vertex
$$(x - \textcolor{#6d3fc4}{2})^2 - \textcolor{#6d3fc4}{1}$$

vertex $(2, -1)$

Example

The function $f(x) = x^2 - 4x + 3$ is graphed in the $xy$-plane. Which equivalent form of $f$ displays the coordinates of the vertex of the graph as constants?

  1. A)$f(x) = (x - 2)^2 - 1$
  2. B)$f(x) = (x - 1)(x - 3)$
  3. C)$f(x) = x^2 - 4x + 3$
  4. D)$f(x) = (x + 2)^2 - 1$
Process of Elimination:
  • Choice A: Vertex form: $h = 2$ and $k = -1$ are right there as constants. Expanding checks it: $(x-2)^2 - 1 = x^2 - 4x + 3$. ✓
  • Choice B: Equivalent, but it displays the x-intercepts $1$ and $3$—not the vertex.
  • Choice C: Equivalent, but standard form displays only the y-intercept $3$.
  • Choice D: Not equivalent: $(x + 2)^2 - 1 = x^2 + 4x + 3$. The sign inside the parentheses is opposite the vertex's $x$-coordinate—$(x - 2)$ means $h = +2$.

Vertex from the Zeros

Given factored form, the vertex costs two steps: by symmetry, its $x$-coordinate is the midpoint of the zeros; then evaluate.

Example

What is the minimum value of $g(x) = (x - 1)(x - 3)$?

$$x = \frac{1 + 3}{2} = 2$$
Vertex $x$: midpoint of the zeros $1$ and $3$
$$g(2) = (2 - 1)(2 - 3) = -1$$
Evaluate — the minimum value is $-1$
“Displays as constants” means read, don't compute. If finding the feature from a given form takes algebra, that form doesn't display it.
Advanced MathNonlinear Functions: Exponential Functions

Exponential Functions

An exponential function multiplies by the same factor at every step instead of adding the same amount:

$$f(x) = \textcolor{#0f6cbd}{a} \cdot \textcolor{#0e8a7e}{b}^{\,x}$$
a — initial value, $f(0)$ · b — the factor per step: growth if $b > 1$, decay if $0 < b < 1$
Growth: $b > 1$
Decay: $0 < b < 1$

Percent Change Lives Inside the Factor

Words in the problemFactor $b$
“increases $5\%$ per year”$1 + 0.05 = 1.05$
“decreases $20\%$ per year”$1 - 0.20 = 0.80$
“doubles each hour”$2$
“loses half its value each day”$0.5$
Example

A bacteria culture starts with $500$ cells, and the population triples every hour. Which function gives the population $P(t)$ after $t$ hours?

  1. A)$P(t) = 500 \cdot 3^{t}$
  2. B)$P(t) = 3 \cdot 500^{t}$
  3. C)$P(t) = 500 + 3t$
  4. D)$P(t) = 500 \cdot \left(\tfrac{1}{3}\right)^{t}$
Process of Elimination:
  • Choice A: Initial value $500$, factor $3$ applied $t$ times. Check $t = 0$: $P(0) = 500$. ✓
  • Choice B: Swaps the roles: at $t = 0$ this gives $P(0) = 3$ cells, not $500$.
  • Choice C: Linear: it adds $3$ cells per hour. “Triples” means multiply, and the growth compounds.
  • Choice D: A factor of $\frac{1}{3}$ is decay—the culture would shrink, not triple.
Example

The value of a car is modeled by $V(t) = 8{,}000(0.75)^t$, where $t$ is the number of years from now. What does the model predict the value will be in $2$ years—and what does the $0.75$ mean?

$$V(2) = 8{,}000(0.75)^2$$
Substitute $t = 2$
$$V(2) = 8{,}000(0.5625)$$
Exponent first: $0.75 \times 0.75$
$$V(2) = 4{,}500$$
The predicted value is $\$4{,}500$

And since $0.75 = 1 - 0.25$, the model says the car loses $\textcolor{#157f4b}{25\%}$ of its value each year—the factor keeps $75\%$, so it loses the other $25\%$.

A factor of $0.75$ means a $25\%$ decrease, not a $75\%$ one. The factor is what's kept; the percent change is what's gained or lost: $b = 1 + r$ for growth, $b = 1 - r$ for decay.
Advanced MathNonlinear Functions: Linear or Exponential?

Linear or Exponential?

Given a table, the test is one comparison away. Check equal steps of $x$:

Rule: Constant differences → linear (add the same amount). Constant ratios → exponential (multiply by the same factor).

Example
$x$$f(x)$$g(x)$
$0$$5$$5$
$1$$10$$10$
$2$$20$$15$
$3$$40$$20$
  • $f$ is exponential: $5 \to 10 \to 20 \to 40$ multiplies by $2$ each step — $f(x) = 5 \cdot 2^x$
    Both functions match at $x = 0$ and $x = 1$ — you must check a third row to tell them apart.
  • $g$ is linear: $5 \to 10 \to 15 \to 20$ adds $5$ each step — $g(x) = 5x + 5$
    Constant difference, straight-line graph.
Example
$x$$h(x)$
$0$$81$
$1$$27$
$2$$9$
$3$$3$

The table gives values of the function $h$. Which equation defines $h$?

  1. A)$h(x) = 81 \cdot \left(\tfrac{1}{3}\right)^{x}$
  2. B)$h(x) = 81 - 54x$
  3. C)$h(x) = \tfrac{1}{3} \cdot 81^{x}$
  4. D)$h(x) = 81 \cdot 3^{x}$
Process of Elimination:
  • Choice A: Each step multiplies by $\frac{27}{81} = \frac{9}{27} = \frac{3}{9} = \frac{1}{3}$: constant ratio, initial value $81$. Every row checks.
  • Choice B: Linear, built from the first step's drop of $54$. It matches two rows, then predicts $h(2) = -27$—the table says $9$.
  • Choice C: Swaps initial value and factor: $h(0)$ would be $\frac{1}{3}$, not $81$.
  • Choice D: Factor $3$ grows; the table shrinks. Direction matters.
Check at least three rows. Linear and exponential models can agree at two points—the third one exposes the impostor.
Advanced MathNonlinear Functions: Practice

Practice

Name the family first—quadratic or exponential—then the job: evaluate, pick a form, build a model, or match a table.

Practice
  1. 1.

    The function $f$ is defined by $f(x) = 2x^2 - 3x$. What is the value of $f(-2)$?

    1. A)$-14$
    2. B)$-2$
    3. C)$2$
    4. D)$14$

    The correct answer is D. Parentheses around the negative input keep every sign honest:

    $$f(-2) = 2(-2)^2 - 3(-2)$$
    Substitute $(-2)$ for each $x$
    $$f(-2) = 2(4) + 6$$
    $(-2)^2 = 4$; subtracting $-6$ adds $6$
    $$f(-2) = 14$$
    Add
    Process of Elimination:
    • Choice A: $-14$ flips the sign of everything—a global sign slip, usually from rushing the two negatives at once.
    • Choice B: $-2$ squares without parentheses: treating $(-2)^2$ as $-4$ gives $-8 + 6 = -2$.
    • Choice C: $2$ gets the square right but misses the double negative: $8 - 6 = 2$ treats $-3(-2)$ as $-6$.
    • Choice D: $2(4) + 6 = 14$. Both negatives handled. ✓
  2. 2.

    The function $g$ is defined by $g(x) = (x - 3)^2 - 8$. What is the minimum value of $g$?

    1. A)$-8$
    2. B)$3$
    3. C)$1$
    4. D)$8$

    The correct answer is A. Vertex form hands you the answer: the vertex is $(3, -8)$, and since $a = 1 > 0$ the parabola opens up, so the vertex's $y$-value is the minimum.

    Process of Elimination:
    • Choice A: Minimum value $= k = -8$, reached at $x = 3$.
    • Choice B: $3$ is where the minimum happens (the $x$-coordinate), not the minimum value itself.
    • Choice C: $1$ is $g(0) = 9 - 8$—the y-intercept, not the minimum.
    • Choice D: $8$ drops the sign of $k$: the vertex sits $8$ below the x-axis.
  3. 3.

    Nadia deposits $\$400$ in an account that earns $6\%$ interest each year, compounded annually. Which function gives the account's value $A(t)$, in dollars, after $t$ years?

    1. A)$A(t) = 400(1.06)^{t}$
    2. B)$A(t) = 400(0.06)^{t}$
    3. C)$A(t) = 400(1.6)^{t}$
    4. D)$A(t) = 400 + 1.06t$

    The correct answer is A. Growing $6\%$ per year means keeping $100\%$ and adding $6\%$: the factor is $1 + 0.06 = 1.06$.

    Process of Elimination:
    • Choice A: $400$ initial, multiplied by $1.06$ each year. Check $t = 1$: $\$424$—up $6\%$. ✓
    • Choice B: The classic: $0.06$ is the $6\%$, but as a factor it means keeping only $6\%$—the account would collapse to $\$24$ in one year.
    • Choice C: $1.6$ is a $60\%$ raise—a decimal-place slip on the rate.
    • Choice D: Linear: adds about a dollar a year and never compounds. Interest earns interest—that's the exponential part.
  4. 4.
    $x$$f(x)$
    $0$$4$
    $1$$12$
    $2$$36$
    $3$$108$

    The table gives values of the function $f$. Which equation defines $f$?

    1. A)$f(x) = 4 \cdot 3^{x}$
    2. B)$f(x) = 3 \cdot 4^{x}$
    3. C)$f(x) = 8x + 4$
    4. D)$f(x) = 4 \cdot 9^{x}$

    The correct answer is A. Ratios first: $\frac{12}{4} = \frac{36}{12} = \frac{108}{36} = 3$—constant ratio, so exponential with factor $3$ and initial value $f(0) = 4$.

    Process of Elimination:
    • Choice A: $4, 12, 36, 108$: every row checks. ✓
    • Choice B: Swapped roles: $f(0)$ would be $3$, but the table says $4$. Always test $x = 0$ first—it's the fastest eliminator.
    • Choice C: Linear bait: matches the first two rows ($4$ and $12$), then predicts $20$ where the table says $36$.
    • Choice D: $9$ is the ratio across two steps ($4 \to 36$). The factor is per single step of $x$.

Things to Remember

  • Quadratic $f(x) = ax^2 + bx + c$: opens up if $a > 0$, down if $a < 0$; y-intercept $c$; vertex at $x = -\frac{b}{2a}$ (or midway between the zeros); symmetric about the vertex.
  • Three forms, three features: standard shows the y-intercept, factored shows the zeros, vertex form shows the vertex. “Displays as constants” = read it, don't compute it.
  • In $(x - h)^2 + k$, the sign flips: $(x - 2)^2$ puts the vertex at $x = \textcolor{#5c6a7d}{+}2$. The minimum/maximum value is $k$, and it happens at $x = h$.
  • Exponential $f(x) = a \cdot b^x$: $a$ is the initial value, $b$ the per-step factor—$b = 1 + r$ for growth, $b = 1 - r$ for decay. $0.85$ means a $15\%$ decrease.
  • Tables: constant differences → linear; constant ratios → exponential. Check three rows—two can lie.
  • Substitute negative inputs in parentheses: $(-3)^2 = 9$, but $-3^2 = -9$.
