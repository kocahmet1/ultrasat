Systems of Linear Equations

A system of linear equations is two equations about the same two variables. A solution of the system is a pair $(x, y)$ that makes both equations true at the same time—each equation alone has infinitely many solutions, but the system usually pins down exactly one.

Graphically, each equation is a line, and the system's solution is where the lines intersect—the one point that sits on both:

Strategies

  • The solution must satisfy both equations. A pair that works in only one is the test's favorite trap.
  • Substitution shines when a variable is already isolated (or has coefficient $1$).
  • Elimination shines when coefficients line up—or can be scaled to line up.
  • Compare slopes to count solutions: crossing lines, parallel lines, or the same line twice.
  • When the choices are pairs, plug them into both equations—no solving required.
  • Asked for a combination like $x + y$? Try adding or subtracting the equations before solving for anything.
Substitution and elimination always both work—the skill being tested is picking the one that's faster for the given system.
AlgebraSystems of Linear Equations: Solve by Substitution

Solve by Substitution

When one equation hands you a variable—already isolated, or easy to isolate—substitute that expression into the other equation. The system collapses into a one-variable equation you already know how to solve.

Rule: Isolate → substitute into the other equation → solve → back-substitute for the second variable.

Example
$$\begin{cases} y = 2x - 1 \\ 3x + y = 14 \end{cases}$$

The first equation already says what $y$ is—so replace $y$ in the second:

$$3x + (2x - 1) = 14$$
Substitute $2x - 1$ for $y$
$$5x - 1 = 14$$
Combine the $x$-terms
$$x = 3$$
Add $1$, divide by $5$
$$y = 2(3) - 1 = 5$$
Back-substitute $x = 3$ into $y = 2x - 1$

Check in both: $5 = 2(3) - 1$ ✓ and $3(3) + 5 = 14$ ✓ — the solution is $(3, 5)$.

Example
$$\begin{cases} x + 4y = 14 \\ 2x - 3y = 6 \end{cases}$$

Nothing is isolated yet—but $x$ has coefficient $1$ in the first equation, so isolating it costs one step:

$$x = 14 - 4y$$
Isolate $x$ in the first equation
$$2(14 - 4y) - 3y = 6$$
Substitute into the second equation
$$28 - 11y = 6$$
Distribute, then combine $-8y - 3y$
$$y = 2$$
Subtract $28$, divide by $-11$
$$x = 14 - 4(2) = 6$$
Back-substitute — the solution is $(6, 2)$
Substitute into the other equation. Plugging the expression back into the equation it came from just produces $14 = 14$—true, and useless.
AlgebraSystems of Linear Equations: Solve by Elimination

Solve by Elimination

Elimination adds or subtracts whole equations so that one variable cancels. It's the fast lane whenever the coefficients of a variable are equal or opposite—and a small multiplication can make them so.

Example
$$\begin{cases} 3x + 2y = 19 \\ 5x - 2y = 21 \end{cases}$$

The $y$-coefficients are opposites ($+2$ and $-2$), so adding the equations wipes $y$ out:

$$8x = 40$$
Add the equations — the $y$-terms cancel
$$x = 5$$
Divide both sides by $8$
$$3(5) + 2y = 19$$
Plug $x = 5$ into either equation
$$y = 2$$
The solution is $(5, 2)$

Scale First, Then Eliminate

Example
$$\begin{cases} 2x + 3y = 12 \\ 3x + 4y = 17 \end{cases}$$

No coefficients match yet. Multiply each equation so the $x$-coefficients agree (both become $6$):

$$6x + 9y = 36$$
First equation $\times\, 3$
$$6x + 8y = 34$$
Second equation $\times\, 2$
$$y = 2$$
Subtract — the $x$-terms cancel
$$2x + 3(2) = 12 \;\Rightarrow\; x = 3$$
Back-substitute — the solution is $(3, 2)$

The Shortcut the SAT Loves

Some questions never ask for $x$ or $y$ alone—they ask for a combination like $x + y$. Before solving, try simply adding (or subtracting) the equations as they stand:

Example
$$\begin{cases} 4x + y = 14 \\ x + 4y = 16 \end{cases}$$

What is the value of $x + y$?

$$5x + 5y = 30$$
Add the two equations
$$x + y = 6$$
Divide both sides by $5$ — done

Solving fully would produce fractions ($x = \frac{8}{3}$, $y = \frac{10}{3}$)—a sign the question was designed for the shortcut. Ugly individual values, clean combination.

When the target is $x + y$, $x - y$, or something like $3x + 3y$, look at what adding or subtracting the equations produces before you grind through a full solve.
AlgebraSystems of Linear Equations: How Many Solutions?

How Many Solutions?

Two lines can cross once, never, or be the same line—so a system has exactly one solution, none, or infinitely many. Slopes and intercepts decide which:

The two linesSlopes & interceptsSolutions
Cross at one pointdifferent slopesExactly one
Parallelsame slope, different interceptsNone
The same linesame slope, same interceptInfinitely many
Exactly one
None
Infinitely many

Rule: In standard form: if you can scale one equation so the $x$- and $y$-coefficients match the other's, then matching constants mean infinitely many solutions, and different constants mean no solution.

Example
$$\begin{cases} 2x + 5y = 9 \\ 4x + ky = 11 \end{cases}$$

In the system above, $k$ is a constant. For which value of $k$ does the system have no solution?

  1. A)$10$
  2. B)$5$
  3. C)$2.5$
  4. D)$20$
$$4x + 10y = 18$$
First equation $\times\, 2$ — now the $x$-coefficients match
$$k = 10$$
Same $y$-coefficient makes the lines parallel…
$$11 \neq 18$$
…and different constants keep them from being the same line
Process of Elimination:
  • Choice A: With $k = 10$, the left sides are perfect multiples but the right sides aren't—parallel lines, no solution.
  • Choice B: $5$ just copies the first equation's $y$-coefficient without scaling it by the same factor as the $x$-terms.
  • Choice C: $2.5$ scales down ($5 \div 2$) while the $x$-coefficients scale up ($2 \to 4$)—the ratios must match in the same direction.
  • Choice D: $20$ doubles twice. With $k = 20$ the slopes differ, so the lines cross and the system has exactly one solution.
“No solution” and “infinitely many” questions look identical until the last step: check the constants. Matching coefficients + matching constants = same line; matching coefficients + different constants = parallel.
AlgebraSystems of Linear Equations: Systems from Context

Systems from Context

A system shows up in a word problem whenever a story places two constraints on the same two unknowns. The classic pair: the counts add up, and the values add up.

Constraint in the storyEquation it becomes
The counts add up (“$250$ tickets were sold”)$x + y = \text{total count}$
The values add up (“sales totaled $\$2{,}450$”)$ax + by = \text{total value}$
Example

A museum sold $250$ tickets one day: adult tickets for $\$12$ and student tickets for $\$7$. Ticket sales totaled $\$2{,}450$. How many adult tickets were sold? Let $a$ and $s$ be the numbers of adult and student tickets:

$$\begin{cases} a + s = 250 \\ 12a + 7s = 2{,}450 \end{cases}$$
$$7a + 7s = 1{,}750$$
Count equation $\times\, 7$
$$5a = 700$$
Subtract it from the value equation — $s$ cancels
$$a = 140$$
Divide by $5$: $140$ adult tickets (and $s = 110$)

Check: $140 + 110 = 250$ ✓ and $12(140) + 7(110) = 1{,}680 + 770 = 2{,}450$ ✓

Example

A food truck sells tacos for $\$3$ each and burritos for $\$8$ each. During one lunch, the truck sold $45$ items for a total of $\$210$. Which system of equations gives the number of tacos $t$ and burritos $b$ sold?

  1. A)$t + b = 45;\;\; 3t + 8b = 210$
  2. B)$t + b = 45;\;\; 8t + 3b = 210$
  3. C)$t + b = 210;\;\; 3t + 8b = 45$
  4. D)$11(t + b) = 210$
Process of Elimination:
  • Choice A: Counts add to $45$ items; values add to $210$ dollars, with each taco worth $3$ and each burrito $8$. (Solving gives $t = 30$, $b = 15$.)
  • Choice B: Swaps the prices—it charges $\$8$ per taco and $\$3$ per burrito.
  • Choice C: Swaps the totals: $210$ is dollars and $45$ is items. Units first, always.
  • Choice D: One equation can't carry two constraints—and no single item costs $\$11$.
Label your variables in writing before building equations (“$t$ = tacos”). Half of all system-from-context errors are really labeling errors.
AlgebraSystems of Linear Equations: Practice

Practice

Pick your method before you compute: is something isolated (substitute)? Do coefficients align (eliminate)? Is the question about $k$ (compare ratios) or a combination like $x + y$ (add the equations)?

Practice
  1. 1.
    $$\begin{cases} y = 3x - 5 \\ 2x + y = 10 \end{cases}$$

    What is the solution $(x, y)$ to the system above?

    1. A)$(3, 4)$
    2. B)$(4, 3)$
    3. C)$(1, -2)$
    4. D)$(5, 0)$

    The correct answer is A. Substitute $3x - 5$ for $y$ in the second equation:

    $$2x + (3x - 5) = 10$$
    Substitute
    $$5x = 15$$
    Combine and add $5$
    $$x = 3, \;\; y = 3(3) - 5 = 4$$
    Back-substitute
    Process of Elimination:
    • Choice A: $4 = 3(3) - 5$ ✓ and $2(3) + 4 = 10$ ✓ — true in both equations.
    • Choice B: $(4, 3)$ swaps the coordinates—and satisfies neither equation.
    • Choice C: $(1, -2)$ satisfies the first equation only ($-2 = 3 - 5$), but $2(1) + (-2) = 0 \neq 10$. One out of two isn't a solution.
    • Choice D: $(5, 0)$ satisfies the second equation only ($10 + 0 = 10$), but $3(5) - 5 = 10 \neq 0$. Same trap, other equation.
  2. 2.
    $$\begin{cases} 5x + 2y = 26 \\ 3x - 2y = 6 \end{cases}$$

    If $(x, y)$ is the solution to the system above, what is the value of $y$?

    1. A)$3$
    2. B)$4$
    3. C)$8$
    4. D)$13$

    The correct answer is A. Opposite $y$-coefficients beg for elimination:

    $$8x = 32$$
    Add the equations — $y$ cancels
    $$x = 4$$
    Divide by $8$
    $$5(4) + 2y = 26 \;\Rightarrow\; y = 3$$
    Back-substitute into either equation
    Process of Elimination:
    • Choice A: $2y = 26 - 20 = 6$, so $y = 3$. Check: $3(4) - 2(3) = 6$ ✓
    • Choice B: $4$ is the value of $x$—the question asks for $y$. Answer the variable that was asked.
    • Choice C: $8$ is the coefficient of $x$ after adding the equations, not a value of $y$.
    • Choice D: $13$ is $26 \div 2$—dividing the first equation's constant without eliminating anything first.
  3. 3.
    $$\begin{cases} kx - 6y = 10 \\ 2x - 3y = 5 \end{cases}$$

    In the system above, $k$ is a constant. If the system has infinitely many solutions, what is the value of $k$?

    1. A)$4$
    2. B)$-4$
    3. C)$2$
    4. D)$12$

    The correct answer is A. Infinitely many solutions means the two equations are the same line. Scale the second equation to match the first:

    $$4x - 6y = 10$$
    Second equation $\times\, 2$
    $$k = 4$$
    Coefficients and constant all match the first equation
    Process of Elimination:
    • Choice A: With $k = 4$, the first equation is exactly the second times $2$—one line drawn twice.
    • Choice B: $-4$ flips the sign: $-4x - 6y = 10$ has a different slope, so the lines cross once.
    • Choice C: $2$ copies the second equation's $x$-coefficient without scaling—the $y$-terms and constants then don't match.
    • Choice D: $12$ scales the $x$-term by $6$ while the $y$-term was scaled by $2$—proportions must match across the whole equation.
  4. 4.

    Zoe buys pens for $\$2$ each and notebooks for $\$5$ each. She buys $12$ items in total and spends $\$39$. How many notebooks does she buy?

    1. A)$3$
    2. B)$5$
    3. C)$6$
    4. D)$7$

    The correct answer is B. Two constraints, two equations—counts and dollars:

    $$\begin{cases} p + n = 12 \\ 2p + 5n = 39 \end{cases}$$
    $$2p + 2n = 24$$
    Count equation $\times\, 2$
    $$3n = 15$$
    Subtract it from the money equation
    $$n = 5$$
    Divide by $3$: $5$ notebooks (and $p = 7$ pens)
    Process of Elimination:
    • Choice A: $3$ divides the $15$ by the notebook price $5$ instead of by the coefficient $3$.
    • Choice B: $n = 5$. Check: $7 + 5 = 12$ items ✓ and $2(7) + 5(5) = 14 + 25 = 39$ dollars ✓
    • Choice C: $6$ assumes an even split of the $12$ items—the prices make that impossible at $\$39$.
    • Choice D: $7$ is the number of pens. Solved correctly, answered the wrong question—the most preventable miss on the whole test.

Things to Remember

  • A system's solution satisfies both equations—graphically, it's the intersection of the two lines. Traps satisfy exactly one.
  • Substitute when a variable is isolated or has coefficient $1$; eliminate when coefficients match or are opposites (scale first if needed).
  • Always back-substitute to get the second variable, and check the pair in both equations.
  • Counting solutions: different slopes → one; same slope, different intercepts → none; same line → infinitely many. For $k$-questions, scale one equation and compare—constants decide between none and infinite.
  • Context: counts add up and values add up—two equations. Define your variables in writing first.
  • Asked for $x + y$ or another combination? Add or subtract the equations before solving fully—especially if full solving looks ugly.
  • Answer the variable the question asked for—$x$ when it wants $x$, $y$ when it wants $y$.
