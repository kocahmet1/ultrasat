Linear Functions

A function is a rule that turns an input into exactly one output. A linear function is a function whose output changes at a constant rate: every time the input goes up by $1$, the output changes by the same amount. Its graph is a straight line, and its rule can always be written in one form:

$$f(x) = \textcolor{#0f6cbd}{m}x + \textcolor{#157f4b}{b}$$
m — the slope: how much $f$ changes per one unit of $x$ · b — the y-intercept: the starting value $f(0)$

Almost every SAT Linear Functions question is one of four jobs: evaluate the function at an input, find the slope from two points or a table, build the equation from given information, or interpret $m$ and $b$ in a real-world story.

Strategies

  • $f(c)$ means substitute. Replace every $x$ in the rule with $c$ and simplify—the result is the output.
  • Read $m$ and $b$ before anything else. The slope is the number multiplying $x$; the y-intercept is the constant.
  • Slope from two points: divide the change in output by the change in input—in the same order.
  • In context: “per” and “each” point to the slope; “initial,” “base fee,” and “starting” point to the y-intercept.
  • Check candidate equations against every point or table row—wrong choices are built to match just one.
Every fact about a linear function is a point on its line. $f(4) = 9$ and “the point $(4, 9)$ is on the graph” are the same sentence in two languages—translate freely between them.
AlgebraLinear Functions: Function Notation

Function Notation

Think of a function as a machine: an input goes in, the rule runs, an output comes out. The notation $f(x)$—read “$f$ of $x$”—names the output that the rule $f$ produces from the input $x$.

Input $x$→Rule $f$→Output $f(x)$
$f(x)$ is not “$f$ times $x$.” The parentheses hold the input; they don't multiply.

Rule: $f(c)$ means: substitute $c$ for every $x$ in the rule. The result is a number—and the point $(c, f(c))$ lies on the graph of $f$.

Example

The function $f$ is defined by $f(x) = 3x + 5$. What is the value of $f(4)$?

$$f(4) = 3(4) + 5$$
Replace every $x$ with $4$
$$f(4) = 12 + 5$$
Multiply
$$f(4) = 17$$
Add

So $f(4) = 17$—and the point $(4, 17)$ is on the graph of $f$.

Working Backward

Questions also run the machine in reverse: they give you the output and ask for the input. Set the rule equal to the output and solve—this is exactly the equation-solving from the previous lesson.

Example

For the function $f(x) = 3x + 5$, the value of $f(a)$ is $26$. What is the value of $a$?

$$3a + 5 = 26$$
Set the rule equal to the output $26$
$$3a = 21$$
Subtract $5$ from both sides
$$a = 7$$
Divide both sides by $3$

Check: $f(7) = 3(7) + 5 = 26$ ✓

AlgebraLinear Functions: Slope: the Rate of Change

Slope: the Rate of Change

The slope measures how fast the output changes: how much $f$ rises (or falls) each time $x$ increases by $1$. From any two points on the line, the slope is the change in $y$ divided by the change in $x$:

$$m = \frac{\textcolor{#157f4b}{\text{rise}}}{\textcolor{#a8621a}{\text{run}}} = \frac{y_2 - y_1}{x_2 - x_1}$$
Example

The graph of the linear function $f$ passes through the points $(2, 5)$ and $(6, 17)$. What is the slope of the graph of $f$?

$$m = \frac{17 - 5}{6 - 2}$$
Subtract the coordinates in the same order
$$m = \frac{12}{4}$$
Simplify each difference
$$m = 3$$
Divide — $f$ grows by $3$ per unit of $x$
Mixing the order — $\frac{y_2 - y_1}{x_1 - x_2}$ — flips the sign of the slope. Pick an order and use it in both the top and the bottom.

On a graph, the slope is the rise over the run between any two points on the line—here, a rise of $4$ over a run of $2$ gives $m = \frac{4}{2} = 2$:

AlgebraLinear Functions: Intercepts & Building the Equation

Intercepts & Building the Equation

The two intercepts are the line's landmark points. The y-intercept is where the line crosses the $y$-axis: set $x = 0$, giving the point $(0, b)$. The x-intercept is where it crosses the $x$-axis: set $f(x) = 0$ and solve.

Example

Consider the linear function $f(x) = -2x + 6$. Its y-intercept is $(0, 6)$, read directly from the rule. For the x-intercept, solve $f(x) = 0$:

$$0 = -2x + 6$$
Set $f(x)$ equal to $0$
$$2x = 6$$
Add $2x$ to both sides
$$x = 3$$
Divide both sides by $2$ — the x-intercept is $(3, 0)$

From Two Points to the Equation

Rule: Slope first, intercept second: compute $m$ from the two points, then plug either point into $f(x) = mx + b$ to find $b$.

Example

The graph of the linear function $f$ passes through $(2, 9)$ and $(5, 18)$. Which equation defines $f$?

$$m = \frac{18 - 9}{5 - 2} = \frac{9}{3} = 3$$
Slope from the two points
$$9 = 3(2) + b$$
Plug the point $(2, 9)$ into $f(x) = 3x + b$
$$b = 3$$
Solve for $b$
$$f(x) = 3x + 3$$
Assemble the rule

Check with the other point: $f(5) = 3(5) + 3 = 18$ ✓

From a Table

A table shows a linear function when the output changes by a constant step for equal steps of $x$. That constant step (per one unit of $x$) is the slope, and the row with $x = 0$ hands you the y-intercept.

Example
$x$$f(x)$
$0$$8$
$1$$11$
$2$$14$
$3$$17$

The table shows four values of the linear function $f$. Which equation defines $f$?

  1. A)$f(x) = 3x + 8$
  2. B)$f(x) = 8x + 3$
  3. C)$f(x) = 3x + 11$
  4. D)$f(x) = 11x + 8$
Process of Elimination:
  • Choice A: Each $+1$ step in $x$ adds $3$ to $f(x)$, so $m = 3$; and $f(0) = 8$, so $b = 8$. Every row checks out.
  • Choice B: Swaps the roles: it uses the starting value as the rate and the rate as the starting value. Already fails at $f(0) = 3 \neq 8$.
  • Choice C: Grabs $f(1) = 11$ as the y-intercept—but $b$ is the value at $x = 0$, not $x = 1$.
  • Choice D: Matches the table at $x = 0$ but nowhere else: $f(1)$ would be $19$, not $11$. One matching row is not enough.
Test candidate equations against every row of the table. Wrong choices are engineered to match exactly one.
AlgebraLinear Functions: Linear Models in Context

Linear Models in Context

In word problems, a linear function is a story with two numbers: something starts at a value and changes at a steady rate. That's the same skeleton you used for equations from context:

Output=Starting value+Rate×Input
Words in the problemPart of $f(x) = mx + b$
“per,” “each,” “every,” “for every additional”the slope $m$
“initial,” “base fee,” “starting amount,” “when $x = 0$”the y-intercept $b$
Example

The function $C(h) = 35h + 50$ gives the total cost, in dollars, of a landscaping job that takes $h$ hours. What is the best interpretation of the number $50$ in this context?

  1. A)The cost of each additional hour of work
  2. B)A fixed charge that does not depend on the number of hours
  3. C)The total cost of a job that takes one hour
  4. D)The number of hours a typical job takes
Process of Elimination:
  • Choice A: The per-hour cost is the number multiplied by $h$—that's the slope, $35$.
  • Choice B: $50$ is the constant term: it's the cost when $h = 0$, charged before any hourly work—a fixed fee.
  • Choice C: A one-hour job costs $C(1) = 35 + 50 = 85$ dollars, not $50$.
  • Choice D: $50$ is measured in dollars, not hours—the units don't match this interpretation.

Build the Model, Read the Intercepts

Example

A water tank holds $240$ gallons and drains at a constant $15$ gallons per minute. The volume after $t$ minutes is:

$$V(t) = \textcolor{#0f6cbd}{240} - \textcolor{#0e8a7e}{15}t$$
240 — starting volume (the y-intercept) · 15 — drain rate per minute (the slope is $-15$)

The intercepts are the story's key moments—when does it start, and when does it end?

$$V(0) = 240$$
y-intercept — the tank starts full
$$0 = 240 - 15t$$
x-intercept — set $V(t) = 0$ for the empty tank
$$t = 16$$
Divide $240$ by $15$ — empty after $16$ minutes
Units are a free answer check: the slope's units are always output units per input unit (gallons per minute), and the intercepts carry the output's units. An interpretation with mismatched units is wrong—no algebra needed.
AlgebraLinear Functions: Practice

Practice

Before opening each answer: name the job—evaluate, find the slope, build the equation, or interpret. Then do only that job.

Practice
  1. 1.

    The function $f$ is defined by $f(x) = 7 - 2x$. What is the value of $f(3)$?

    1. A)$-1$
    2. B)$1$
    3. C)$5$
    4. D)$15$

    The correct answer is B. Substitute $3$ for $x$: $f(3) = 7 - 2(3) = 7 - 6 = 1$.

    Process of Elimination:
    • Choice A: $-1$ subtracts in the wrong direction: $6 - 7$ instead of $7 - 6$.
    • Choice B: $7 - 2(3) = 1$. Multiplication before subtraction.
    • Choice C: $5$ computes $7 - 2$ first and never uses the input—$f(3)$ means $x = 3$ everywhere.
    • Choice D: $15$ computes $(7 - 2) \cdot 3$: order of operations broken twice.
  2. 2.

    The function $g$ is linear, $g(1) = 4$, and $g(5) = 16$. What is the value of $g(9)$?

    1. A)$20$
    2. B)$24$
    3. C)$28$
    4. D)$48$

    The correct answer is C. Find the rate, then ride it forward:

    $$m = \frac{16 - 4}{5 - 1} = \frac{12}{4} = 3$$
    Slope from the two known points
    $$g(9) = 16 + 3(9 - 5)$$
    From $x = 5$ to $x = 9$ is $4$ steps of $+3$
    $$g(9) = 28$$
    Or build the rule: $g(x) = 3x + 1$, and $g(9) = 28$
    Process of Elimination:
    • Choice A: $20$ adds the $x$-step ($+4$) to $g(5)$ instead of adding $4$ steps of the slope.
    • Choice B: $24$ is $3(9 - 1)$: the total growth from $x = 1$, but it forgets to add the starting value $g(1) = 4$.
    • Choice C: $16 + 12 = 28$. Check with the rule $g(x) = 3x + 1$: $g(1) = 4$ ✓ $g(5) = 16$ ✓ $g(9) = 28$ ✓
    • Choice D: $48$ multiplies $g(5) = 16$ by the slope $3$—slopes are added per step, not multiplied onto outputs.
  3. 3.

    The function $T(m) = 90 - 6m$ gives the temperature of a cup of tea, in degrees, $m$ minutes after it is poured. Based on the model, after how many minutes does the model predict a temperature of $0$ degrees?

    1. A)$6$
    2. B)$15$
    3. C)$84$
    4. D)$90$

    The correct answer is B. A temperature of $0$ means $T(m) = 0$—this is the x-intercept:

    $$0 = 90 - 6m$$
    Set the output equal to $0$
    $$6m = 90$$
    Add $6m$ to both sides
    $$m = 15$$
    Divide both sides by $6$
    Process of Elimination:
    • Choice A: $6$ is the cooling rate (degrees per minute), not a time.
    • Choice B: $90 \div 6 = 15$ minutes for the starting $90$ degrees to drain away at $6$ per minute.
    • Choice C: $84$ is $90 - 6$: the temperature after one minute, not the time to reach zero.
    • Choice D: $90$ is the starting temperature—the y-intercept, not the x-intercept.
  4. 4.

    The graph of the linear function $f$ is shown. Which equation defines $f$?

    1. A)$f(x) = 2x - 2$
    2. B)$f(x) = 2x + 2$
    3. C)$f(x) = -2x + 2$
    4. D)$f(x) = \frac{1}{2}x - 2$

    The correct answer is A. Read the two marked points: the y-intercept is $(0, -2)$, so $b = -2$; and from $(0, -2)$ to $(2, 2)$ the rise is $4$ over a run of $2$, so $m = 2$.

    Process of Elimination:
    • Choice A: $m = \frac{2 - (-2)}{2 - 0} = 2$ and $b = -2$. Both marked points satisfy $f(x) = 2x - 2$.
    • Choice B: Drops the sign of the y-intercept: this line would cross the $y$-axis above zero.
    • Choice C: A negative slope means a falling line—the graph clearly rises from left to right.
    • Choice D: $\frac{1}{2}$ is run-over-rise—the slope fraction written upside down.

Things to Remember

  • $f(c)$ is the output at input $c$—substitute and simplify. The point $(c, f(c))$ is on the graph.
  • In $f(x) = mx + b$: m is the slope—the change in $f$ per one unit of $x$; b is the y-intercept, $f(0)$.
  • Slope from two points: $m = \frac{y_2 - y_1}{x_2 - x_1}$—same order top and bottom. In a table, it's the constant step per unit of $x$.
  • y-intercept: set $x = 0$. x-intercept: set $f(x) = 0$ and solve.
  • In context: “per/each” → slope; “initial/base fee/starting” → y-intercept. Check that the units match the interpretation.
  • Test a candidate equation against every given point or row—not just one.
