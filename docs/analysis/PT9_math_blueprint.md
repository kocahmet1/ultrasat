# Practice Test 9 - Math Modules 3 and 4: 44-Slot Blueprint

This blueprint is based on the eight complete math modules in the supplied Practice Tests 4-7
(216 items), the four supplied 100-item Question Bank exports, and the local Tests 1-6 originality
corpus. It intentionally treats the complete-form measurements as ranges rather than rigid rules.

authored as uniformly harder than Module 3. Each module opens with linear fluency and quick
rate/data work, then shifts toward Advanced Math and Geometry. Q22 is hard in both modules.

## Auditable texture quotas

Applied items are M3 Q1, Q2, Q4, Q11, Q14, and Q16, and M4 Q1, Q2, Q5, Q8,
Q10, Q11, and Q21. This gives **13 explicit contexts**, or 29.5%, matching the 29.2%
measured in the complete forms. The data contexts at M3 Q2/Q16 and M4 Q10/Q11/Q21 are
load-bearing rather than decorative.

The 12 SPR targets are:

- Nonnegative integers: M3 Q5 = 3, Q6 = 6, Q13 = 7, Q22 = 12; M4 Q5 = 18,
  Q6 = 7, Q12 = 5, Q13 = 7, Q22 = 18.
- Fractions/decimals: M3 Q12 = 25/3 (also accepts 8.333); M4 Q19 = 25/4
  (also accepts 6.25).
- Negative: M3 Q19 = -2.

The form distributes the principal trap families rather than repeating one surface: wrong target or
composite, input-output/parameter role swap, sign or reversal, percent/exponent semantics, unit
conversion, conditional denominator, statistical scope and sampling variability, radius/diameter or
dimensional scale, solution count/tangency, integer-bound quantifiers, visual translation/scaling,
and slope-versus-intercept identification. Each slot's final column records its load-bearing mechanism and every MC
rationale identifies the adjacent misconception represented by each distractor.

## Authenticity controls

- Every item isolates one mathematical decision; hard items use clean arithmetic after the setup
  is recognized.
- Every MC distractor corresponds to a named adjacent quantity, reversal, step omission, sign
  error, unit slip, or role swap.
- Numeric choices are monotonic unless a representation family makes ordering inapplicable.
- Probability appears only in Module 4. Each module contains one circle item.
- Visuals include two tables, two scatterplots, two geometry figures, one ordinary function graph,
  one dot plot, and one medium four-panel answer-choice graph. The transformed-data scatterplot is
  deliberately hard. This preserves measured visual variety and
  includes a real source archetype that earlier local forms omitted.
- No names are used. Contexts avoid the named contexts and biological species used in local Tests
  1-6. No Latin binomial is forced because it appeared only once across the supplied complete forms.
- The outgoing Test 9 questions will be backed up and soft-retired. They will not be deleted.
