(9/7, 8/8 per module). PT4 took (9/7, 8/8), PT5 (8/8, 9/7), PT1 (9/7, 9/7). PT3 re-takes
(9/7, 8/8) deliberately: it is the split closest to the measured pooled mix (E 40.9 / M 31.8 /
H 27.3 against measured 42/32/26), and the remaining unused option (8/8, 8/8) would drop the
easy band to 36.4%, six points below measured — a harder-than-real form. **Difficulty split is
therefore not a differentiation axis for PT3;** the other eight axes above carry the difference.

figures, against the spec §1e reference of 3–4 / 2 / 1–2. The third table is bought by making
M4 Q8 (easy geometry) verbal rather than figured, which is itself attested — PT7 ships ten
geometry items with zero figures.
